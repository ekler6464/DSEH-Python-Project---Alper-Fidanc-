# Human Impact on Mammal Extinctions

Analysis of how human activity has shaped mammal extinctions over the last ~130,000 years,
using body mass, diet and taxonomy of extinct and living species.

## Data
PHYLACINE 1.2 (Faurby et al., 2018), `Trait_data.csv`
https://datadryad.org/dataset/doi:10.5061/dryad.bp26v20
